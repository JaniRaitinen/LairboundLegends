A Webgame project using openweathermap api and a MySQL database. FrontEnd JS, Backend Python. Made in ~2 months

The player's goal is to find all 6 weather crystals from the map. Your dragon gives a riddle that contains the clue to what weather we are searching for.
Openweathermap gives real world data as to where that type of weahter is currently present. The player then has to find it by traveling between real world airport locations named "lairports" for dragons.
When the player has arrived at the weather crystal location a pokemon style turn based battle minigame starts, when won he gains 1 of the 6 weather crystals.

NOTE: Game doesn't work when downloaded as you miss the airport database and openweathermap API keys. The Battle and Flight Minigames can be tested by opening "BattleDebug.html" or "flightGame.html"
